# Handoff

Where this project stands. The facts below are written by a hook and cost
nothing; the intent under them is written by hand, once, when it changes.

## Intent

Teknesyum Base carried its interface standard as a document the model had to read —
about 27,000 tokens of `SKILL.md` and 55,000 more across eight reference files, paid
every time interface work came up. This project is that standard rebuilt as data plus a
deterministic scanner: values live in generated token files, mechanically checkable rules
live in `scan.js`, and only what runs against the model's own default stays in a skill.
Core owns the work relay and has no opinion about how anything looks; all of that opinion
is here.
